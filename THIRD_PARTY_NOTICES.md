# Third-party notices

## Hero visual `assets/hero-torso.webp`

The current hero visual is a **user-provided studio photograph of a male torso**
(no face, no pelvic detail), cropped, keyed to the dark hero background and
colour-graded for this plugin. The repository does **not** claim copyright in
this photograph, and the MIT license in `LICENSE` does **not** apply to it.
Before redistributing the repository, publishing screenshots, or using the
image commercially, confirm that you have the model release / portrait rights
and the copyright or licence required for that use. If you do not, replace
`assets/hero-torso.webp` with an asset you are allowed to publish.

A public-domain fallback exists in the original project:

- **Male torso, Gülhane IAM inv. 5246 T**, Istanbul Archaeological Museums;
  Wikimedia Commons, public domain:
  <https://commons.wikimedia.org/wiki/File:Male_torso_G%C3%BClhane_IAM_inv5246T.jpg>
- The fallback processing notes and the source image are kept outside this
  repository in the original workspace (`art/`).

## Screenshots

The screenshots under `assets/screenshots/` use demo data and the current hero
visual. They are documentation images, not medical records. The same
user-provided-image notice applies.

## Reference ranges

Reference ranges and target values shown by the plugin are population
references or public fitness/nutrition consensus values. They are not medical
standards, personal targets, or prescriptions. The plugin does not ship any
third-party medical dataset.
